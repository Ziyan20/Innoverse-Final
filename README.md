# Amazon Perfumes — Scent of Distinction

A modern luxury perfume e-commerce website designed to provide an elegant and immersive online shopping experience.

## ✨ Features

- 🏠 Luxury-inspired homepage
- 🌸 Perfume collection and product showcase
- 🛍️ Shopping cart
- 💳 Checkout and payment pages
- 🎁 Curated perfume gift sets
- 📦 Order confirmation page
- 📖 Brand story section
- 📞 Contact page
- 🧴 Individual perfume product pages
- 🖥️ Responsive and modern user interface
- ✨ Interactive 3D elements

## 🌹 Perfume Collection

The website features six signature fragrances:

- **Ambre Royal**
- **Blanc de Blanc**
- **Crystal Noir**
- **Lumière Dorée**
- **Nuit d'Or**
- **Rose Éternelle**

## 🎁 Gift Sets

The website also includes curated perfume experiences such as:

- **Luxury Duo**
- **Signature Explorer**
- **Day to Night Journey**

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- Google Fonts
- Cloudflare CDN
